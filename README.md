# GTA RADIO — фанатский концепт-сайт

Статический сайт-прототип: радио «из игр серии GTA». Главная с надписью **GTA RADIO**,
выбор игры (V, IV, San Andreas, Vice City, III) и экран станции «как в машине»:
круговой селектор волн (как в GTA V/IV) или список станций (как в SA/VC/III),
HUD с названием станции и трека, эквалайзер, громкость, переключение стрелками.

**Никакого бэкенда не нужно** — весь сайт это HTML/CSS/JS, идеально ложится на GitHub Pages.

---

## Как посмотреть

**Способ 1 — single-file демо (самый быстрый).** Файл `demo.html` содержит весь сайт
(стили и скрипты внутри): открывается **двойным кликом** на любом компьютере и работает
без сервера и без сети. Звук включается по первому клику.
Пересобрать после правок конфига: `python3 tools/build-demo.py`.

**Способ 2 — локальный сервер (полная многостраничная версия + редактор):**

```bash
cd gta-radio
python3 -m http.server 8000
# открыть http://localhost:8000
```

> Важно: в многостраничной версии чтение ID3-тегов и внешние стримы работают только по `http://`.

**Способ 3 — GitHub Pages** (см. ниже) — ссылка для друзей с телефона.

## Публикация на GitHub Pages

**Способ А — из ветки (рекомендуемый, не требует особых прав токена):**
1. Залей содержимое папки в репозиторий (или `python3 tools/publish.py <файл-с-токеном>`).
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт на `https://<твой-ник>.github.io/<имя-репозитория>/`.
   Каждое следующее изменение в `main` пересобирает сайт автоматически.

**Способ Б — через GitHub Actions** (если хочется Actions): токен должен иметь
права **Workflows: Read and write** (иначе GitHub отклонит пуш файлов `.github/workflows/`).
Верни файл `.github/workflows/deploy.yml` из образца `tools/deploy-actions.yml.sample`,
убери `.github/` из `.gitignore`, запушь и в **Settings → Pages** выбери **Source: GitHub Actions**.

## Куда положить музыку

Всё настраивается в **одном файле `js/config.js`** (или визуально — `editor.html`):

```js
{
  id: "rock", name: "Vinewood Rock", tagline: "classic rock",
  accent: "#ff5b4a", bg: "#3a0d09", motif: "bolt",
  tracks: [
    { type: "file",   src: "v/track-01.mp3" },                          // папка audio/
    { type: "file",   src: "v/track-02.mp3", title: "Название", artist: "Исполнитель" },
    { type: "stream", src: "https://cdn.example.com/radio.mp3" }        // внешний URL
  ],
  demo: { key: "E", bpm: 128, prog: "rock", drums: "rock", noise: 0.02 } // если треков нет
}
```

Три типа источников:

| type     | что это                                                          | особенности |
|----------|------------------------------------------------------------------|-------------|
| `file`   | mp3/ogg в папке `audio/<игра>/…`                                  | путь относительный от `audio/`; ID3-теги читаются сами |
| `stream` | внешняя ссылка (S3, Cloudflare R2, Icecast, любой https)          | сервер обязан отдавать `Access-Control-Allow-Origin: *` |
| `demo`   | процедурная музыка, генерируется WebAudio прямо в браузере        | работает сразу, без единого файла — удобно для прототипа |

Если у станции нет `tracks` — включается `demo`-режим с параметрами из `demo`
(тональность, темп, стиль, барабаны, уровень «шума эфира»). Несколько треков играют по очереди без пауз.

### Хостинг тяжёлых mp3

- **В самом репозитории** — просто, но лимит GitHub: файл ≤ 100 МБ, репозиторий желательно ≤ 1 ГБ.
- **GitHub Releases** — до 2 ГБ на файл; ссылку ставишь как `stream`.
- **Cloudflare R2 / S3 / любой CDN** — лучший вариант для больших библиотек; не забудь CORS-заголовок.
- **Свой сервер (VPS)** — отдавай статику nginx'ом и добавь `add_header Access-Control-Allow-Origin *;` для папки с музыкой.

## Редактор станций

`editor.html` — визуальная правка конфига: станции, цвета, иконки (18 SVG-мотивов),
треки, демо-параметры. Кнопка **«Сгенерировать config.js» → «Скачать файл»** —
заменяешь им `js/config.js` в репозитории и коммитишь. Есть тестовый плеер для проверки ссылки/файла.

## Горячие клавиши экрана радио

`←` `→` — смена волны · `Space` — пауза · `M` — звук · `1…9` — станция по номеру · `Esc` — выход · колесо мыши / свайп — крутить селектор.

## Структура

```
index.html        главная: титул + выбор игры
radio.html        экран «в игре» (колесо или список, тема игры)
editor.html       визуальный редактор config.js
demo.html         single-file сборка всего сайта (открывается двойным кликом)
css/style.css     все стили + темы игр (theme-v / theme-iv / theme-sa / theme-vc / theme-iii)
js/config.js      ЕДИНЫЙ файл содержимого: игры, станции, треки, цвета, иконки
js/audio.js       звук: WebAudio-синтез демо + плеер файлов/стримов + ID3
js/radio.js       логика экрана радио
js/editor.js      логика редактора
audio/…           папки для твоих mp3 (v, iv, sa, vc, iii)
tools/build-demo.py   сборка demo.html из исходников
tools/check.mjs       автотест интерфейса (playwright, не часть сайта)
```

## Добавление своей игры / темы

В `config.js` добавь объект в `games`: `ui: "wheel"|"list"`, `theme: "<имя>"`,
`accent: "#цвет"` — и (по желанию) блок `body.theme-<имя>` в `css/style.css`
с собственным фоном. Всё остальное подхватится автоматически.

## Правовая заметка (важно!)

Это **неофициальный фанатский прототип**: он не содержит ни кода, ни музыки, ни логотипов
Rockstar Games / Take-Two. Названия станций в демо вымышлены, иконки — собственные SVG,
музыка генерируется браузером. Если будешь публиковать сайт:

- не заливай оригинальные радиотреки из игр и не стримь их без прав — это нарушение авторских прав;
- используй собственную музыку, лицензионную (CC0/CC-BY с указанием автора) или демки;
- названия станций и обложки из игр — товарные знаки Rockstar: для публичного сайта безопаснее
  держать вымышленные имена (в конфиге они уже такие), а «настоящие» оставлять для локального пользования;
- дисклеймер уже встроен в подвал и в конфиг (`meta.disclaimer`).

## Идеи для следующих шагов

- эффект «поездки»: лёгкое покачивание фона и доплер при смене волны;
- диджейские вставки между треками (короткие mp3-джинглы в плейлист);
- режим «ночь/день» и погода на фоне под настроение станции;
- PWA: офлайн-кэш интерфейса, установка как приложение;
- страница «плейлисты»: сборка миксов из треков разных игр.
