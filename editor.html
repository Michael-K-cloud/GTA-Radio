Редактор станций

Всё содержимое сайта живёт в одном файле js/config.js. Здесь можно править его визуально: названия, цвета, иконки и — главное — источники звука. Нажми «Сгенерировать config.js» → «Скачать файл» → замени им js/config.js в репозитории и закоммить.

2 · Станции и треки

Как подключить настоящую музыку. У трека три типа источника:
demo — звук генерируется браузером (ничего загружать не надо, работает прямо сейчас);
file — файл в папке audio/, путь относительный, например v/my-track.mp3;
stream — внешняя ссылка (S3, Cloudflare R2, Icecast). Сервер должен отдавать заголовок Access-Control-Allow-Origin: *, иначе браузер заблокирует звук.
Если у станции несколько треков — они играют по очереди без пауз. Названия и исполнители подтягиваются из ID3-тегов mp3 автоматически.

Быстрая проверка звука

Локальный файл должен лежать в папке проекта и сайт должен быть открыт через http:// (например python3 -m http.server), а не двойным кликом по файлу.
